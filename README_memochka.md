# Мёмочка

Telegram-бот для групповых чатов, который не только отвечает на команды, но и пытается вести себя как обычный участник: запоминает локальные приколы, подхватывает стиль переписки, иногда сам влезает в разговор, делает демотиваторы и карточки с цитатами.

Бот написан на Python + aiogram, хранит историю и память в SQLite и использует OpenRouter для AI-функций.

## Что умеет

- самостоятельно вмешиваться в разговор после паузы;
- реагировать на сообщения и прямые обращения;
- хранить историю чата, фотографии, память о людях и локальные факты;
- делать демотиваторы из фотографий чата;
- создавать пиксельные карточки-цитаты;
- пересказывать недавнюю историю переписки;
- показывать профили участников и ручные факты о них;
- собирать интерактивную статистику чата;
- настраивать самостоятельность и хаос прямо из Telegram;
- диагностировать Telegram/OpenRouter/автономный цикл через `/mtest`.

## Команды

### 💬 Чат

| Команда | Что делает |
| --- | --- |
| `/mhis` | кратко пересказывает недавнюю переписку |
| `/mhis 150` | пересказывает указанное количество последних сообщений, от 20 до 200 |
| `/mstats` | открывает интерактивную статистику чата |
| `/mprof` | показывает свой профиль |
| `/mprof @username` | показывает профиль участника |
| `/madd @username факт` | добавляет ручной факт в карточку участника, команда для админов |

`/mprof` и `/madd` также умеют работать через reply на сообщение человека.

### 🖼 Медиа

| Команда | Что делает |
| --- | --- |
| `/mcit` | делает карточку-цитату из сообщения, на которое ответили |
| `/mdem` | делает демотиватор из reply-фото или сохранённой фотографии чата |
| `/mgen` | генерирует реплику в стиле чата |
| `/mgen @username` | делает пародию на стиль конкретного участника |

### ⚙️ Управление

| Команда | Что делает |
| --- | --- |
| `/mset` | меню самостоятельности, шанса вмешательства и хаоса |
| `/mtest` | диагностика автономности и OpenRouter |
| `/mforget` | очищает память текущего чата |
| `/mhelp` | показывает общий список команд |
| `/mvpn` | Маркевич ВПН |

## Обновление за последний месяц 

За месяц бот заметно вырос из набора команд в более цельного участника чата.

### 🤖 Автономность

- Переделан планировщик самостоятельных вмешательств: новые сообщения больше не сбрасывают ожидание бесконечно.
- Добавлен верхний предел ожидания `AUTO_MAX_WAIT_SECONDS`, чтобы активный чат всё равно получал AI-проверку.
- Разделены обычные и idle-вмешательства.
- Добавлены короткие человеческие реакции и автоматические демотиваторы из накопленных фотографий.
- Добавлена `/mtest`, которая проверяет Telegram, базу, активность чата, delayed-task и реальный healthcheck OpenRouter.
- Исправлен runtime-баг в intervention prompt с фигурными скобками JSON внутри f-string.

### 🧠 Память и люди

- Появились профили участников `/mprof`: количество сообщений, любимое слово, типичное время активности и накопленная память.
- Добавлена `/madd`, чтобы админы могли вручную записывать факты в карточку участника.
- Ручные факты хранятся отдельно от AI-памяти, поэтому куратор их не перетирает.
- `/mforget` учитывает и ручные факты.

### 🕰 История чата

- Добавлена `/mhis` — короткий пересказ последних сообщений в стиле Мёмочки.
- Можно выбрать объём истории: например `/mhis 150`.
- Если AI недоступен, команда не падает и использует простой fallback по реальным сообщениям.

### 📊 Интерфейс и статистика

- `/mhelp` переделан в единый аккуратный список команд по разделам.
- `/mstats` стал интерактивным дашбордом с вкладками **Обзор / Люди / Слова / Память**.
- В статистике появились топ участников, топ слов, пик активности, память, фотографии и текущие настройки самостоятельности.
- `/mprof` получил единый визуальный стиль с остальными командами.

### 🖼 Карточки и медиа

- `/mcit` полностью переработан: вместо старого билборда используется светлая минималистичная карточка с пиксельным шрифтом.
- Добавлена адаптация размера текста под длину цитаты.
- Улучшена поддержка символов, кавычек и `@username` в пиксельном шрифте.
- Демотиваторы умеют брать не только reply-фото, но и фотографии из памяти чата.

### 🛠 Под капотом

- OpenRouter вынесен в отдельный AI-слой.
- Настройки самостоятельности хранятся по чатам.
- Добавлены миграции SQLite для новых функций.
- Репозиторий очищен от runtime-мусора: `bot.db`, `.env`, логов и `__pycache__` больше не должны попадать в Git.

## Установка

Требуется Python 3.11+.

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

Linux/macOS:

```bash
source .venv/bin/activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

Создать `.env` из примера:

```bash
cp .env.example .env
```

На Windows можно просто скопировать `.env.example` и переименовать копию в `.env`.

Минимально нужны:

```env
BOT_TOKEN=...
OPENROUTER_API_KEY=...
OPENROUTER_MODEL=google/gemma-4-26b-a4b-it
```

После этого:

```bash
python main.py
```

Для работы с обычными сообщениями группы у Telegram-бота должен быть отключён **Privacy Mode** через BotFather.

## Безопасность

Не коммитьте `.env`, `bot.db`, логи и дампы переписки. `.gitignore` в репозитории уже исключает их.

Если токен Telegram или ключ OpenRouter когда-либо попал в публичный репозиторий, его лучше перевыпустить.
