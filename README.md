## ✦ Кто такая Мёмочка

**Мёмочка** — Telegram-бот с характером и долговременной памятью для групповых чатов.
Она запоминает контекст, участников и локальные приколы, умеет подстраиваться под стиль беседы, реагировать на сообщения и самостоятельно появляться в разговоре, когда это уместно.

Вместо обычного сценария «команда → сухой ответ» бот старается ощущаться как ещё один участник компании.

## ✨ Что умеет

- 🧠 **Помнит чат** — хранит сообщения и использует накопленный контекст.
- 👥 **Различает участников** — может собирать память о конкретных людях.
- 🗣️ **Подхватывает стиль** — использует примеры из беседы при генерации реплик.
- ⚡ **Вмешивается сама** — умеет отвечать без прямой команды и оживлять затихший чат.
- 😼 **Реагирует на сообщения** — короткими репликами и Telegram-реакциями.
- 🖼️ **Делает демотиваторы** — из reply-фото или сохранённых изображений чата.
- 💬 **Создаёт карточки-цитаты** — увековечивает лучшие сообщения компании.
- 🎭 **Пародирует участников** — `/mgen @username` генерирует реплику в узнаваемом стиле.
- 📊 **Показывает статистику памяти** — через `/mstats`.
- 🎛️ **Даёт управлять самостоятельностью** — через `/mset`.

## 🤖 Команды

| Команда | Что делает |
|---|---|
| `/mgen` | Сгенерировать реплику в стиле текущего чата |
| `/mgen @username` | Пародировать конкретного участника |
| `/mdem` | Создать демотиватор из фото / памяти чата |
| `/mcit` | Создать карточку-цитату по reply |
| `/mstats` | Показать память и статистику |
| `/mset` | Настроить самостоятельность Мёмочки |
| `/mvpn` | Маркевич ВПН™ |
| `/mforget` | Очистить память текущего чата *(для админа)* |
| `/mhelp` | Показать справку |

## 🧠 Как это устроено

```text
Telegram
   │
   ▼
┌──────────────┐
│   aiogram    │  ← команды, сообщения, реакции
└──────┬───────┘
       │
       ├──────────────► OpenRouter / LLM
       │                   │
       │                   └─ генерация реплик и решений
       │
       ▼
┌──────────────┐
│    SQLite    │  ← история, участники, память, настройки
└──────┬───────┘
       │
       ├─► стиль чата
       ├─► пользовательская память
       └─► сохранённые фото / локальный контекст
```

Основные модули:

```text
memochka-bot/
├── main.py             # Telegram-роутеры, команды и поведение
├── ai_brain.py         # работа с LLM / OpenRouter
├── memory.py           # формирование контекста и памяти
├── memory_store.py     # долговременная память
├── db.py               # SQLite-слой
├── prompts.py          # характер и промпты Мёмочки
├── demotivator.py      # генерация демотиваторов
├── quote_card.py       # карточки-цитаты
├── config.py           # настройки из окружения
├── assets/             # шаблоны изображений
└── deploy/             # запуск и systemd deployment
```

## 🚀 Быстрый запуск

### 1. Клонируй репозиторий

```bash
git clone https://github.com/murzichek5-spec/memochka-bot.git
cd memochka-bot
```

### 2. Создай виртуальное окружение

**Linux / macOS**

```bash
python -m venv .venv
source .venv/bin/activate
```

**Windows**

```powershell
python -m venv .venv
.\.venv\Scripts\activate
```

### 3. Установи зависимости

```bash
pip install -r requirements.txt
```

### 4. Настрой окружение

Скопируй пример конфига:

```bash
cp .env.example .env
```

На Windows можно просто создать `.env` рядом с `.env.example`.

Минимально нужны:

```env
BOT_TOKEN=your_telegram_bot_token
OPENROUTER_API_KEY=your_openrouter_api_key
```

Остальные параметры уже имеют разумные значения по умолчанию и перечислены в `.env.example`.

### 5. Запусти Мёмочку

```bash
python main.py
```

## 🎛️ Настройка характера

Поведение бота можно менять без правки кода через `.env`.
Например:

```env
AUTO_REPLY_CHANCE=0.50
CREATIVITY=0.64
IDLE_INTERVENTION_CHANCE=0.22
SHORT_REACTION_CHANCE=0.28
AUTO_DEMOTIVATORS_ENABLED=true
```

Так можно сделать Мёмочку спокойнее — или превратить её в участницу, которая слишком уверенно чувствует себя в вашем чате.

Полный список параметров находится в [`.env.example`](./.env.example).

## 🖼️ Мемная машина

Мёмочка умеет работать не только с текстом:

- `/mdem` превращает фотографии в демотиваторы;
- `/mcit` делает визуальную карточку из сообщения;
- бот может использовать накопленные изображения чата для самостоятельных мемных вбросов.

Шаблоны лежат в [`assets/`](./assets/).

## 🖥️ Запуск на сервере

В [`deploy/`](./deploy/) лежат заготовки для постоянного запуска:

```text
deploy/
├── install.sh
├── run.sh
└── memochka.service.example
```

Для Linux-сервера можно использовать `systemd`, чтобы бот автоматически стартовал после перезагрузки и перезапускался при падении.

## 🔐 Безопасность

Никогда не коммить:

```text
.env
bot.db
*.log
```

В `.env` находятся реальные токены, а `bot.db` может содержать историю и память реальных Telegram-чатов.
Эти файлы уже исключены через `.gitignore`.

Если секрет случайно попал в commit, его недостаточно просто удалить из файла — ключ нужно **перевыпустить**, а секрет убрать из Git-истории.

Подробнее: [`SECURITY.md`](./SECURITY.md).
